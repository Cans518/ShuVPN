# 使用指南

## 连接校园网络

1. 在“账户”中登录上海大学统一身份认证账户，按提示完成验证码或企业微信扫码。
2. 返回“连接”，开启需要的 HTTP/SOCKS5 开关，或在设置中配置系统代理/TUN，然后点击连接按钮。连接中可再次点击取消，连接后可点击断开。
3. 首页显示连接阶段、累计上传/下载和 HTTP/SOCKS5 监听地址。未启动的代理不会显示为可用。

HTTP/SOCKS5 只服务于使用这些代理的应用。系统代理和 TUN 在设置中按需开启；配置修改在下一次连接时生效。TUN 可能请求操作系统授权。校园资源访问仍受账户权限限制。

## 窗口与托盘

默认窗口为 420×600，可缩小至 380×540。标题栏空白区域可拖动，右上角分别为最小化和关闭。关闭窗口后 ShuVPN 继续在托盘运行，保持已有连接。退出应用请使用托盘“退出 ShuVPN”或设置页底部的退出按钮。

托盘左键打开窗口，右键显示菜单。可以直接连接、取消或断开，调整下次连接使用的代理/TUN 开关，打开账户、规则、记录和设置。连接中禁止修改代理配置，避免菜单勾选与当前网络状态不一致。

| 托盘标记 | 含义 |
| --- | --- |
| 蓝灰盾牌与斜线 | 未连接 |
| 金色盾牌与圆点 | 正在连接或清理 |
| 绿色盾牌与勾 | 已连接 |
| 红色盾牌与叉 | 需要处理错误 |

图标同时用颜色和符号表示状态；悬停可读到状态文字。再次启动 ShuVPN 会恢复已有窗口。托盘创建失败时，关闭操作改为最小化，保留任务栏恢复入口。

## 外观与启动

设置页提供“晴海、青竹、暮紫、暖砂”四种配色，配合浅色、深色或跟随系统使用。全界面使用随应用打包的霞鹜文楷 GB，无需联网下载字体。

“编辑或导入自定义主题”支持分别编辑明暗颜色、实时预览、撤销、保存，以及导入/导出 JSON。未保存的预览在离开设置页时撤销。主题格式见[自定义主题](themes.md)。

“开机自启动”在当前用户登录系统时启动 ShuVPN，并停留在托盘；它不会自动连接 VPN。便携版本启用后应保留可执行文件路径，移动程序后需要关闭并重新开启此选项。

## 规则与诊断

规则修改先校验预览，再确认应用。输入错误时当前配置继续生效；可回退上一份配置。连接记录显示当前会话的实际路由决策。

如果断开或退出提示清理失败，请保留程序并按提示重试。报告问题时提供系统、版本、复现步骤与错误文字，移除账户、密码、验证码、Cookie 和校园个人信息。
